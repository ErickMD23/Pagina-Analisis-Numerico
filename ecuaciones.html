I. Ecuaciones Diferenciales Ordinarias

1.1 Método de Euler

El método de Euler es una técnica numérica para aproximar la solución de ecuaciones diferenciales ordinarias (EDO) usando pasos pequeños.

Ejemplo

Para y' = -2y, con y(0) = 1 y h = 0.1:

Paso 1:
y₁ = y₀ + h * f(x₀, y₀)
y₁ = 1 + 0.1 * (-2 * 1) = 1 - 0.2 = 0.8

Paso 2:
y₂ = y₁ + h * f(x₁, y₁)
y₂ = 0.8 + 0.1 * (-2 * 0.8) = 0.8 - 0.16 = 0.64

Resultado:
y₀ = 1, y₁ = 0.8, y₂ = 0.64
La aproximación converge hacia la solución exacta: y(x) = e^(-2x).

1.2 Método de Runge-Kutta

El método de Runge-Kutta (RK) de cuarto orden es más preciso que el método de Euler y utiliza cuatro pasos intermedios en cada iteración.

Ejemplo

Para y' = x + y, con y(0) = 1 y h = 0.2:

Paso 1: Calcular los valores intermedios.
k₁ = h * f(x₀, y₀) = 0.2 * (0 + 1) = 0.2
k₂ = h * f(x₀ + h/2, y₀ + k₁/2) = 0.2 * (0.1 + 1.1) = 0.24
k₃ = h * f(x₀ + h/2, y₀ + k₂/2) = 0.2 * (0.1 + 1.12) = 0.244
k₄ = h * f(x₀ + h, y₀ + k₃) = 0.2 * (0.2 + 1.244) = 0.2888

Paso 2: Calcular la siguiente aproximación.
y₁ = y₀ + (k₁ + 2k₂ + 2k₃ + k₄) / 6
y₁ = 1 + (0.2 + 2(0.24) + 2(0.244) + 0.2888) / 6 = 1.243

Resultado:
y(0.2) ≈ 1.243 (aproximación numérica).

1.3 Resolución de Sistemas de Ecuaciones Diferenciales Ordinarias de Primer Orden

Para resolver sistemas de EDOs de primer orden, se pueden usar métodos como Euler o Runge-Kutta.

Ejemplo

Para el sistema:

x' = -y
y' = x
Con condiciones iniciales: x(0) = 1, y(0) = 0, y paso h = 0.1.

Usando el método de Euler:
Paso 1:
x₁ = x₀ + h * (-y₀) = 1 + 0.1 * (0) = 1
y₁ = y₀ + h * (x₀) = 0 + 0.1 * (1) = 0.1

Paso 2:
x₂ = x₁ + h * (-y₁) = 1 + 0.1 * (-0.1) = 0.99
y₂ = y₁ + h * (x₁) = 0.1 + 0.1 * (1) = 0.2

Resultado:
x₁ = 1, y₁ = 0.1
x₂ = 0.99, y₂ = 0.2
El sistema sigue una trayectoria circular, como se espera.
