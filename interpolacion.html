I. Interpolación

1.1 Mínimos Cuadrados

El método de mínimos cuadrados se utiliza para encontrar la mejor línea que ajuste un conjunto de puntos minimizando la suma de los cuadrados de las diferencias (errores) entre los puntos observados y la línea.

Ejemplo

Dado el conjunto de puntos (x, y) = {(1, 1), (2, 2), (3, 2)}, ajustemos una línea y = mx + b:

Paso 1: Calcular m (pendiente):
m = Σ(xi - x̄)(yi - ȳ) / Σ(xi - x̄)²
m = (1*1 + 0*0 + 1*0) / (1² + 0² + 1²) = 0.5

Paso 2: Calcular b (intersección):
b = ȳ - m * x̄
b = 1.67 - 0.5 * 2 = 0.67

Resultado: y = 0.5x + 0.67

1.2 Método de Lagrange

El método de Lagrange encuentra un polinomio de interpolación que pasa exactamente por un conjunto de puntos dados.

Ejemplo

Dado (1, 1), (2, 4), (3, 9), encontremos el polinomio de interpolación:

L1(x) = (x - 2)(x - 3) / ((1 - 2)(1 - 3)) = (x - 2)(x - 3) / 2
L2(x) = (x - 1)(x - 3) / ((2 - 1)(2 - 3)) = -(x - 1)(x - 3)
L3(x) = (x - 1)(x - 2) / ((3 - 1)(3 - 2)) = (x - 1)(x - 2) / 2

P(x) = 1 * L1(x) + 4 * L2(x) + 9 * L3(x)
P(x) = x² (polinomio exacto).

1.3 Método de Interpolación de Newton

Este método utiliza diferencias divididas para construir el polinomio de interpolación de forma iterativa.

Ejemplo

Dado (1, 1), (2, 4), (3, 9), construyamos el polinomio:

Tabla de diferencias divididas:
x    f(x)    Δf1    Δf2
1    1
     (4-1)/(2-1) = 3
2    4        3
     (9-4)/(3-2) = 5
     (5-3)/(3-1) = 1
3    9        5       1

Polinomio:
P(x) = f(1) + Δf1(x - 1) + Δf2(x - 1)(x - 2)
P(x) = 1 + 3(x - 1) + 1(x - 1)(x - 2)
P(x) = x² (interpolación exacta).
