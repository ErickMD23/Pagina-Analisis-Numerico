I. Diferenciación Numérica

La diferenciación numérica utiliza diferencias finitas para aproximar derivadas de funciones.

1.1 Método de Diferencias hacia Adelante

Aproxima la derivada con los valores futuros de la función.

Ejemplo

Para f(x) = x² en x = 2 usando h = 0.1:

f'(2) ≈ (f(2.1) - f(2)) / 0.1 = (4.41 - 4) / 0.1 = 4.1
La derivada exacta es f'(x) = 2x → f'(2) = 4 (precisión aceptable).

1.2 Método de Diferencias hacia Atrás

Aproxima la derivada con los valores pasados de la función.

Ejemplo

Para f(x) = x² en x = 2 usando h = 0.1:

f'(2) ≈ (f(2) - f(1.9)) / 0.1 = (4 - 3.61) / 0.1 = 3.9
La derivada exacta es f'(x) = 2x → f'(2) = 4 (error pequeño).

1.3 Método de Diferencias Centrales

Utiliza valores tanto hacia adelante como hacia atrás para mejorar la precisión.

Ejemplo

Para f(x) = x² en x = 2 usando h = 0.1:

f'(2) ≈ (f(2.1) - f(1.9)) / (2 * 0.1) = (4.41 - 3.61) / 0.2 = 4.0
La derivada exacta es f'(x) = 2x → f'(2) = 4 (resultado exacto).

II. Integración Numérica

La integración numérica aproxima el valor de una integral definida mediante métodos discretos.

2.1 Método del Trapecio

Divide el intervalo en trapecios y suma sus áreas.

Ejemplo

Aproximemos ∫₀¹ x² dx con n = 2 subintervalos:

h = (1 - 0) / 2 = 0.5
∫₀¹ x² dx ≈ (h / 2) * [f(0) + 2f(0.5) + f(1)]
= (0.5 / 2) * [0 + 2(0.25) + 1] = 0.375
Valor exacto: 1/3 ≈ 0.333 (buena aproximación).

2.2 Método de Romberg

Combina las reglas del trapecio para mejorar la precisión mediante extrapolación.

Ejemplo

Aproximemos ∫₀¹ x² dx:

Paso 1: Calcular T(h₁) y T(h₂) con diferentes particiones.
Paso 2: Extrapolar usando:
R₂₁ = (4T(h₂) - T(h₁)) / 3
Resultado: ∫₀¹ x² dx ≈ 0.333 (valor exacto).

2.3 Métodos de Simpson

Usa parábolas para aproximar el área bajo la curva.

Ejemplo

Aproximemos ∫₀¹ x² dx con el método de Simpson (n = 2):

h = (1 - 0) / 2 = 0.5
∫₀¹ x² dx ≈ (h / 3) * [f(0) + 4f(0.5) + f(1)]
= (0.5 / 3) * [0 + 4(0.25) + 1] = 0.333
Resultado exacto: 1/3.

2.4 Cuadratura de Gauss

Utiliza puntos y pesos específicos para calcular integrales con alta precisión.

Ejemplo

Aproximemos ∫₋₁¹ x² dx usando cuadratura de Gauss con 2 puntos:

Puntos: x₁ = -√(1/3), x₂ = √(1/3)
Pesos: w₁ = w₂ = 1
∫₋₁¹ x² dx ≈ Σ wᵢ * f(xᵢ)
= 1*f(-√(1/3)²) + 1*f(√(1/3)²) = 1/3 + 1/3 = 2/3
Valor exacto: 2/3 (coincide con el resultado).
