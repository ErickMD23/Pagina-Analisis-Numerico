I. Análisis de errores y graficación

El análisis de errores estudia las desviaciones entre la solución exacta y la solución aproximada. Se dividen en dos tipos principales:

Error absoluto: Diferencia entre el valor exacto y el valor aproximado. 

Error absoluto = |x_exacto - x_aproximado|

Error relativo: Error absoluto dividido por el valor exacto. 

Error relativo = |x_exacto - x_aproximado| / |x_exacto|

Ejemplo

Si el valor exacto de π es 3.141592 y tenemos una aproximación de 3.14:

Error absoluto: |3.141592 - 3.14| = 0.001592
Error relativo: 0.001592 / 3.141592 ≈ 0.000506

Graficación

La graficación nos permite visualizar el comportamiento de las soluciones aproximadas y exactas.

Ejemplo: Graficar f(x) = x² - 2 nos permite visualizar la raíz de la ecuación x² = 2.

II. Series de Taylor y Mc Laurin

Las series de Taylor y Mc Laurin son representaciones de funciones como una suma infinita de términos calculados a partir de sus derivadas.

Serie de Taylor:
f(x) ≈ f(a) + f'(a)(x - a) + f''(a)(x - a)² / 2! + ...

Serie de Mc Laurin (caso especial con a = 0):
f(x) ≈ f(0) + f'(0)x + f''(0)x² / 2! + ...

Estas series son útiles para aproximar funciones complejas mediante polinomios.

III. Exactitud y Precisión

Exactitud: Qué tan cercano está un valor medido o calculado al valor verdadero.

Precisión: Qué tan consistente es un conjunto de mediciones entre sí, independientemente del valor verdadero.

Ejemplo

Un termómetro mide la temperatura de un cuerpo en °C:

Valor verdadero: 37°C

Medidas registradas: 36.9°C, 37.1°C, 36.8°C

Análisis:

Exactitud: Alta porque las mediciones están cerca del valor verdadero.

Precisión: Alta porque las mediciones son consistentes entre sí.

Ejercicio:

Un estudiante mide la longitud de un objeto cuya medida verdadera es 10 cm. Obtiene los siguientes resultados:

Mediciones: 9.8 cm, 10.2 cm, 10.1 cm, 9.9 cm

Evalúa la exactitud de las mediciones con respecto al valor verdadero.

Evalúa la precisión de las mediciones comparándolas entre sí.

IV. Error Absoluto y Relativo

Ejemplo

Queremos calcular la raíz cuadrada de 2:

Valor verdadero: 1.41421

Valor aproximado: 1.41

Cálculos:

Error absoluto: |1.41421 - 1.41| = 0.00421
Error relativo: 0.00421 / 1.41421 ≈ 0.00297 (o 0.297%)

Ejercicio:

El valor verdadero de \( π \) es 3.14159265, pero se utiliza 3.14 en un cálculo aproximado.

Calcula el error absoluto.

Calcula el error relativo en porcentaje.

V. Números de punto flotante en 32 y 64 bits

Los números de punto flotante son representaciones de números reales en computadoras. Los formatos más comunes son:

32 bits (precisión simple): Representa aproximadamente 7 cifras significativas.

64 bits (doble precisión): Representa aproximadamente 15-16 cifras significativas.

Ejemplo: Un número decimal como 3.14159265:

32 bits: Almacena aproximadamente 3.141592.

64 bits: Almacena aproximadamente 3.14159265358979.
