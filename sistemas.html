I. Sistemas de Ecuaciones Lineales

1.1 Método de Gauss

El método de Gauss elimina incógnitas transformando el sistema de ecuaciones en una matriz triangular para resolverlo por sustitución hacia atrás.

Ejemplo

Resolvamos el sistema:

2x + y - z = 1
4x - 6y = -2
-2x + 7y + 2z = 9

Transformamos a una matriz triangular:
[2  1 -1 |  1]     [2  1 -1 |  1]     
[4 -6  0 | -2]  →  [0 -8  2 | -4]  ...
Sustitución hacia atrás:
z = 1, y = 2, x = 3.
Solución: x = 3, y = 2, z = 1

1.2 Método de Gauss-Jordan (Matriz Inversa)

Extiende el método de Gauss convirtiendo la matriz a forma escalonada reducida.

Ejemplo

Resolvamos el sistema:

x + y + z = 6
2x - y + 3z = 14
y - z = -1

Formamos la matriz aumentada y la reducimos:
[1  1  1 |  6]    →   [1  0  0 | 1]
[2 -1  3 | 14]    →   [0  1  0 | 2]
[0  1 -1 | -1]    →   [0  0  1 | 3]

Solución: x = 1, y = 2, z = 3.

1.3 Método LU y Choleski

Descompone la matriz del sistema en una matriz triangular inferior (L) y una superior (U).

Ejemplo

Resolvamos el sistema:

2x + 3y = 8
4x + 7y = 18

Descomponemos en L y U:
L = [1  0]   U = [2  3]
    [2  1]       [0  1]

Resolviendo L y U:
Primero Ly = b, luego Ux = y:
y₁ = 4, y₂ = 2.
Solución: x = 2, y = 1.

1.4 Método de Gauss-Seidel

Itera las soluciones de las ecuaciones hasta alcanzar la convergencia.

Ejemplo

Resolvamos el sistema:

x + y + z = 6
2x + y + z = 9
3x + 3y + z = 14

Iteración inicial (x₀ = 0, y₀ = 0, z₀ = 0):
x₁ = (6 - y₀ - z₀)/1 = 6
y₁ = (9 - 2x₁ - z₀)/1 = -3
z₁ = (14 - 3x₁ - 3y₁)/1 = 5
Repetimos hasta que converja:
x ≈ 1, y ≈ 2, z ≈ 3.

II. Sistemas de Ecuaciones No Lineales

En este caso, se aplican métodos iterativos para encontrar soluciones aproximadas.

2.1 Método de Newton para 2 Ecuaciones

Utiliza derivadas parciales para iterar hasta la solución.

Ejemplo

Resolvamos:

f₁(x, y) = x² + y² - 4
f₂(x, y) = x² - y - 1

Inicializamos en (x₀, y₀) = (1, 1).
Iteramos usando:
J = | ∂f₁/∂x  ∂f₁/∂y |  → Jacobiano
    | ∂f₂/∂x  ∂f₂/∂y |

Hasta que converja:
Solución: x ≈ 1.32, y ≈ 1.12.
